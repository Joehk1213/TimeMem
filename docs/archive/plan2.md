# TimeMem PWA：四條 ASCII 魚細改規劃

## 目標與邊界

只在現有暖紙風 PWA 背景加入四條以鍵盤字元組成、慢慢往返游動的魚。保留現有前景、示範內容及互動，不接後端、不保存輸入；此文件是細改計劃，Joe 批准前不改任何 PWA 檔案。

本次是 Joe 指定的 Server 前端例外；只限這次已批准的範圍。往後按 SKILL 回復 Desktop 開發、Server 只運行。規劃不記錄完整內網地址、登入資料或其他秘密。

## 1. 現有外殼與不可更動項目

目前暖紙白底和中文 CSS 變數已建立；頂欄、中央「而家諗緊咩？」與輸入框、示範列表、空白／載入／錯誤示範狀態、回顧卡及示範標籤均已存在。輸入只作當頁示範、不會保存，頂欄和卡片的「示範」標示及「輸入不會保存」說明必須保持可見。

目前四張示範記憶卡位於全頁背景層，使用低幅度 `transform` 漂移與縮放，卡片各自以不同時長錯開；滑鼠移入可開回顧卡，回顧卡開啟時以 `body.回顧已開啟` 暫停卡片。現有焦點還原、觸控／鍵盤入口、減少動效和窄屏規則都保留。

以下內容不得改動或移除：暖紙底色與既有版面；中央問句、輸入、卡片、列表及所有示範狀態；輸入不保存／不接後端；示範標籤；回顧卡及焦點行為；320px 不爆版、對比與按鈕尺寸要求；現有記憶卡的內容和互動。

## 2. 四條魚的組成與游動方式

- 四條魚只用純文字鍵盤字元，不用圖檔、圖示字型、外部資源、重 3D、閃爍或逐格 JavaScript 動畫。字形可用 `><(((('>`，反方向以相反字形或水平翻轉呈現；魚是裝飾，不向輔助科技重複讀出。
- 以四個獨立文字元素和 CSS `transform` 往返動畫實作；只動畫合成友善的位移，不改版面尺寸，不加逐影格計時器或新依賴。
- 初始分配如下；值是待實測的起點，不代表已驗證的效能或最終位置：

| 魚 | 字級 | 往返週期 | 初始方向 | 垂直泳道 | 相位 |
|---|---:|---:|---|---|---|
| 一 | 0.8rem | 64 秒 | 左向右 | 上方外圍約 8vh | 0 秒 |
| 二 | 1rem | 78 秒 | 右向左 | 上方外圍約 14vh | 延後約 19 秒 |
| 三 | 0.72rem | 96 秒 | 左向右 | 下方外圍約 88vh | 延後約 37 秒 |
| 四 | 0.9rem | 112 秒 | 右向左 | 下方外圍約 94vh | 延後約 61 秒 |

- 泳道只在畫面外圍安全帶內往返，不穿過中央主欄；依視窗寬度限制游距，並以不同高度、字級、週期和相位避免同速齊游或碰在一起。魚沿用既有次要文字色並以低存在感呈現；魚是 `aria-hidden` 裝飾，不能降低正文、控制項或焦點的對比。
- 新增的 CSS 自訂變數一律用中文名稱，例如 `--魚一字級`、`--魚一速度`、`--魚一高度`、`--魚一游距`、`--魚一相位`，其餘三條依相同規則命名；重用既有色彩變數，不另造英文設計變數。

## 3. 與示範記憶卡協作、避免遮擋

- 把魚的裝飾容器放在現有記憶背景容器內，並置於 JavaScript 動態加入的記憶卡之前。沿用背景容器現有裁切和底層堆疊；讓後加入的記憶卡、中央內容、頂欄、列表、按鈕及回顧對話框都維持在魚上方。
- 魚及其容器設定不接收指標事件，不能攔截任何點擊或觸控。魚只在背景泳道移動，不改記憶卡的位置、速度、抽選、文字或開卡規則。
- 桌面泳道避開四張卡所在的外圍角落和中央主欄；窄屏保留四條魚，但縮細字形、縮短游距，安排在外側安全帶。320px、列表展開、狀態面板顯示及輸入取得焦點時，都要實測魚是否干擾文字；如有重疊，只調整魚的泳道／字級／游距，不犧牲前景可讀性或操作。

## 4. 暫停、恢復與減少動效

- 回顧卡開啟時沿用 `body.回顧已開啟` 狀態，暫停四條魚和現有記憶卡。
- 以既有滑鼠指標判斷流程追蹤指標是否仍停留在觸發記憶卡。關閉回顧卡後，若指標仍在該卡上，魚繼續暫停；指標離開後才恢復。鍵盤開卡仍由回顧卡狀態暫停；鍵盤關卡後焦點還原規則不變。
- 恢復時沿用原動畫相位，不重設到起點，不跳位；滑鼠或觸控操作不會被魚影響。
- 系統偏好減少動態效果時，四條魚完全靜止，不做位移、縮放或閃爍；現有記憶卡減少動效行為保持不變。
