# TimeMem — 屋企 Home Hub 包裝版

**定位：唔係一個 App，唔係一個軟件，係屋企多一部長開嘅電子設備。**
**一句講晒：舊電腦翻新用，好似 ROUTER 咁，屋企長開，當一個家庭個人整合集，好似 NAS 咁，多一個長期插火牛嘅電子設備咁上下。**

**重點：唔好用技術名去講，要用屋企已經有嘅嘢去講。**
- ROUTER：屋企已經有，長開，插火牛 + 插 LAN 線，唔使理佢，唔見咗佢會冇 WiFi。
- NAS：有啲屋企有，長開，插火牛 + 插 LAN 線，唔使理佢，唔見咗佢會冇相睇。
- TimeMem Home Hub：同上面一樣，長開，插火牛 + 插 LAN 線，唔使理佢，唔見咗佢會搵唔返滑板班幾時、打針幾時。

## TimeMem Home Hub 係咩

**定義：**
- 一部舊電腦，翻新用，唔好掉，唔好賣。
- 裝咗 TimeMem，專門做屋企嘅家庭個人整合集。
- 長期插火牛，長期插 LAN 線，長期開住，鎖住畫面，唔使理佢。
- 你唔會直接用呢部機，你會用電話去用佢，好似你唔會直接用 ROUTER，你會用 WiFi 咁。

**佢唔係咩：**
- 唔係你日日用嚟做嘢嗰部電腦。JOE-SERVER 唔係 JOE-DESKTOP，唔好撈埋。
- 唔係要買嘅新硬件。唔賣 Box，唔賣機，係舊電腦翻新用。
- 唔係 Cloud。資料喺屋企呢部機，唔上雲，唔出去。

**佢係咩：**
- 屋企嘅記憶中心：學校 PDF、滑板班、羽毛球、打針、證件到期、學費、相片、回憶，全部喺晒呢部機。
- 屋企嘅提問中心：問「下一堂滑板班幾時？」3-5 秒有答案，唔使喺 WhatsApp 搵。
- 屋企嘅相片牆：開 TimeMem，隨機相片 + 故事卡片，睇返以前啲回憶。

## 外觀包裝，點樣擺

**擺位，好似 ROUTER 咁擺：**

- 擺喺邊：廳嘅櫃上面、書房嘅枱上面、近 ROUTER 嘅位，唔好擺喺床上面，唔好擺喺被上面，唔好放入櫃，唔好放入袋。
- 點擺：平放，底要通風，唔好遮住風扇位，唔好疊嘢喺上面。
- 插咩：插火牛 + 插 LAN 線，2 條線就夠，好似 ROUTER 咁，2 條線。
- 著咩燈：著住電源燈，唔好熄，熄咗即係有問題。
- 鎖住：WIN+L 鎖機，或者合上蓋，畫面鎖咗，唔使理佢，唔好俾小朋友撳到入去。

**如果你見到佢，你會見到：**
- 一部舊 Laptop，合埋蓋，或者一部舊 Desktop，個 Mon 熄咗。
- 插住火牛，插住 LAN 線，著住燈。
- 唔使開，唔使理，佢自己行緊。

**如果你唔見佢，你會點：**
- 唔會點，因為你唔會直接用佢，你用電話去用佢。
- 電話開 TimeMem，見到相片牆，問到問題，搵到資料，就係佢喺度做嘢。

## 舊電腦翻新，點樣翻新

**邊啲舊電腦用得：**
- 舊 Laptop，FUJITSU LIFEBOOK U9311X 呢啲，i7，16GB，477GB，絕對用得。
- 舊 Desktop，i5 以上，16GB RAM，500GB SSD，用得。
- 唔使買新，唔使買 Box，舊電腦翻新用，環保，唔嘥。

**翻新步驟，3 步：**

1.  **清機：** 將舊電腦入面啲舊資料備份走，洗咗佢，裝返 Windows 11，乾淨。
2.  **一鍵安裝：** 跑 `Install-OneClick.ps1`，自動裝 Docker、拉 Model、還原 TEMP BACKUP，問「要打開 TimeMem 嗎？」
3.  **變做 Home Hub：** 跑 `Set-Server-Lock-Simple.ps1`，自動設合蓋 = 唔做任何嘢 + 永不睡眠 + 鎖機，插火牛 + 插 LAN 線，擺喺枱面，搞掂。

**翻新完，佢就唔再係「舊電腦」，佢係「屋企嘅 Home Hub」。**
- 唔好再喺上面做 Word、做 Excel、打機。
- 佢專門做 TimeMem，專門做屋企嘅家庭個人整合集。
