# AI 協作規則備忘錄（AI-AGREEMENT）

## 決策與任務即時落地

- **拒絕純對話停留**：討論出任何新架構、新測試流程、技術選型或重要共識後，AI 必須主動將內容落地，唔可只留喺對話。
- **架構決策同步**：重要設計、決策及限制寫入 `docs/DECISIONS.md`。
- **待辦事項同步**：待驗證項目、M1／M2 清單及執行步驟寫入 `docs/working/TODO.md`。
- **閉環驗證**：Meta 共識完成後，應形成可追溯嘅 Repo 設計、測試清單或決策紀錄。

## 資安鐵律（Rule-SEC-01）

- 絕對禁止將真實密碼、API Key、真實 `.env`、私人家庭個資或真實相片寫入任何會由 Git 追蹤、公開分享或送入外部服務嘅檔案。
- 公開設定只可依賴 `.env.example` 等脫敏範本；真實 credentials 及私密資料只可留喺本機受控位置。
- 測試資料必須使用合成資料；任何個人化附件、OCR 結果、thumbnail、embedding、log 或 backup 未經 Joe 明確批准前，不得進入公開 repo 或 Cloud。

## 語言規範

- 專案記錄、進度、決策及待辦預設使用繁體廣東話。
- 專有名詞、代碼、ID、路徑及技術棧保持英文。
