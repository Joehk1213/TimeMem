# TimeMem Home Hub — 物理擺位，標準版

**機器：JOE-SERVER，FUJITSU LIFEBOOK U9311X**
**擺法：買個架，將部機企係度，左邊插電源，右邊插 LAN 線，擺喺 ROUTER 隔離。**
**一句講晒：好似 ROUTER 咁企喺度，長開，唔使理。**

---

## 點解咁擺先啱

### 1. 有內置 LAN PORT，直插 LAN 線，唔使轉插
- JOE-SERVER 有內置 LAN PORT，直插 LAN 線就得，唔使 USB-C 轉 LAN、唔使 Dock、唔使轉插。
- 轉插成日鬆、成日唔見咗、成日要再買，煩。
- 直插就穩，插咗唔好掂佢，唔會鬆，Tailscale 唔會斷，第一次 Search 唔會因為網絡斷咗而慢。
- **標準：** LAN 線直插，唔好經轉插。

### 2. 買個架，將部機企係度，方便散熱
- Laptop 平放喺枱面，底會焗住，散熱差，長開 7x24 會熱。
- 企係度，兩邊通風，底唔會焗住，熱氣向上走，風扇唔使咁辛苦。
- 企係度，仲要慳位，唔使佔成個枱面，好似 ROUTER 咁企喺度，唔阻埞。
- **架要點揀：** 鋁合金直立式 Laptop 架，唔好買膠架，膠架唔散熱。架要穩，唔好一掂就跌。唔使貴，幾十蚊到一百蚊就得。

### 3. 左邊插電源，右邊插 LAN 線
- U9311X 左邊係電源，右邊係 LAN，左電源右 LAN，兩條線分開，唔會打結。
- 左邊電源線，向左去拖板；右邊 LAN 線，向右去 ROUTER，兩條線唔會交叉，睇落乾淨。
- 如果要拔，左手拔電源，右手拔 LAN，一手一邊，唔使諗。
- **標準：** 左電源，右 LAN，唔好調轉，唔好打結。

### 4. 擺喺 ROUTER 隔離
- ROUTER 隔離，LAN 線最短，唔使拉長線，唔使經過成間屋。
- ROUTER 隔離，嗰個位本身已經係「長開電子設備區」，多一部機，家人唔會覺得怪。
- ROUTER 隔離，嗰個位本身已經有拖板，有 LAN 位，唔使再拉拖板。
- **感覺：** 擺喺 ROUTER 隔離，成個畫面就係「屋企嘅網絡區」，ROUTER + Home Hub，一齊企喺度，好合理。

## 擺位圖，文字版

```
        牆
        |
  [拖板]    [ROUTER]
     |         |
     |         |  ← 短 LAN 線，唔好長
     |         |
  [電源線]   [LAN 線]
     |         |
     |         |
  ┌──────┐  ┌──────┐
  │      │  │      │
  │ 電源 │  │ LAN  │  ← 左邊電源，右邊 LAN
  │      │  │      │
  └──────┘  └──────┘
     \         /
      \       /
       \     /
        [ 架 ]
        [ 架 ]  ← 鋁合金直立架，企係度
        [ 架 ]
       JOE-SERVER
     U9311X 企係度
     合埋蓋，鎖住畫面
     著住燈，長開

  枱面 / 櫃面，通風，唔好遮風扇位
```

**唔好咁擺：**
- 唔好平放喺床上面、被上面，會焗親。
- 唔好放入櫃，唔好放入袋，會焗親。
- 唔好疊嘢喺上面，會焗親。
- 唔好擺喺窗邊曬太陽，會熱。

**要咁擺：**
- 企係度，通風，近 ROUTER，左電源右 LAN，插火牛 + 插 LAN 線，著住燈，唔使理。

## 日常檢查，1 秒就得

- 睇下燈有冇著，著住即係行緊。
- 睇下 LAN 線有冇鬆，冇鬆就得。
- 睇下風扇有冇嘈，冇嘈到好大聲就得。
- 唔使開蓋，唔使撳掣，唔使理佢。

**如果燈熄咗：**
- 睇下火牛有冇鬆，拖板有冇跳掣。
- 睇下 LAN 線有冇鬆。
- 重新開機，跑一次 `Install-OneClick.ps1`，睇下 Docker 起唔起返。

---

## 呢個擺法，點解好合理

- **物理合理：** 企係度散熱好，左電源右 LAN 唔打結，近 ROUTER LAN 線最短。
- **心理合理：** 擺喺 ROUTER 隔離，家人會覺得「哦，咪又係多個 ROUTER 咁嘅嘢」，唔會覺得「你又搞緊啲好煩嘅嘢」。
- **可複製合理：** 下一個家庭，照抄呢個擺法，買個架，左電源右 LAN，擺喺 ROUTER 隔離，10 分鐘搞掂，唔使諗。
